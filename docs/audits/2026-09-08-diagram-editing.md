# 图表原位编辑回归（2026-09-08）

## 范围与实现

- 所有 Mermaid/ECharts 围栏统一显示“编辑此图表”，按能力选择现有画布、结构化表单或源码预览。
- 桑基图增加来源、目标、数值表格；完整支持 CSV 引号和逗号。无法解析的高级配置回退源码，禁止静默丢弃。
- 图表替换保留原引擎、围栏、缩进、换行；校验原文快照和文档会话，一次事务完成替换。
- ECharts 表单修改在原配置上更新数据，保留背景、标题样式、系列样式等，复杂数据结构回退源码。
- 实测发现 Mermaid 11.17.2 Sankey CSV 词法规则仅接受 ASCII；构建脚本对两处文本字符类追加 Unicode 范围，保留 CSV 分隔符、转义规则及 HTML 清理。依赖升级导致规则不匹配时构建失败，要求重新审查。
