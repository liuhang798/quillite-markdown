## 修复的问题

| 问题 | 原因与影响 | 修复 |
|---|---|---|
| 异步保存串入其他文档 | 保存返回前切换文件，旧结果可能更新新文件；仅判断路径也无法区分关闭后重开的同名文档 | 为文档建立会话编号，保存、另存、权限检测与磁盘刷新统一检查会话 |
| 保存中输入的内容失去未保存提示 | 后端写完旧快照便清除 dirty；前端退出编辑后也可能误判已全部保存 | 后端不再提前清除 dirty；前端比较当前正文与提交快照，确认后才更新状态 |
| 打开文件请求乱序 | 较早请求晚返回时覆盖后来打开的文档，等待期间新增修改可能被丢弃 | 最新打开请求优先，应用结果前复核会话及正文；新增编辑需再次确认 |
| 范例另存后仍像只读文件 | 更新文档对象后没有同步访问控件和阅读页路径 | 统一刷新只读样式、编辑与保存按钮、真实文件路径 |
| AI 修改落入错误文档 | 旧选区或插入位置在切换文档后仍可能有效 | AI 选区绑定会话，打开文件及关闭预览清理旧请求状态，应用前再次校验 |
| 导出失败破坏目标 | 原实现 rename 失败后直接删除目标再重试，甚至能删除同名空目录 | 同目录暂存并一次替换；失败保留原目标，清理自身临时文件 |
| 偏好写入不完整风险 | 直接写 preferences.json，写入中断可能留下截断文件 | 改为完整写入、Sync、Close 后替换 |
| 文档图表提供可执行配置 | 图表 JSON 可控制 HTML tooltip、危险链接、数据视图标签及阻塞型正则 | 强制 richText 提示框；过滤危险 URL、原型字段，转义标签并拒绝不可信正则筛选 |
| 词云过小且字号全部相同 | 样式规范化给每个词写入 14px，覆盖词频和 sizeRange | 仅默认设置字体与颜色，不强行指定字号；用户显式字号仍有效 |
