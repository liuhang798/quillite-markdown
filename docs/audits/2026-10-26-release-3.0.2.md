# v3.0.2 pre-release verification

## Included changes

Merged the current application sources, including PicGo CLI preparation, login,
upload verification and progress, document links, direct draft saves, chart
selection, large-document loading, outline equations and Spell check menus.
Generated binaries/dependencies and unrelated submission artwork are excluded.
Updated application, installer, frontend and documentation versions to 3.0.2.

## Local verification

- JavaScript unit/regression suite: 1,938 passed.
- Production frontend build, Go tests and `go vet ./...`: passed.
- Source-level release safety gate: 63 passed.
- PicGo CLI settings/preparation UI: Chinese and English passed.
- Upload failure, fallback, session isolation and manual retry: 21/21 passed
  across PicGo Server, Cloud and CLI using synthetic services. The browser test
  now waits for the target document after asynchronous loading before editing.
- Chromium and WebKit: Spell check menus and reading/editing/inline/export TOC
  equations passed, including keyboard use, narrow layouts and safe rendering.
- Opt-in official component acceptance: Windows download, integrity checks,
  isolated npm install and CLI startup passed; macOS x64/arm64 and Linux x64
  archive download/integrity/extraction passed. Native execution on those
  platforms and real-account image hosting are not claimed by these tests.
- Full local Windows installer: NSIS core plus custom launcher, footer and
  payload length verified. Size 13,354,027 bytes; SHA-256:
  `248E169903FB4EF627018A5FEF93AC420E935F6FF4D5333DDCE14E3BD1311CA5`.
- `git diff --check` passed. No install/uninstall was run on the user's machine.

## Release gates

GitHub Actions must independently pass Windows/macOS checks, hosted disposable
Windows installer lifecycle tests and all three platform builds before release.
Website publication follows successful upload of all six release assets. The
local installer hash above is not the hash of the independently built CI asset.
