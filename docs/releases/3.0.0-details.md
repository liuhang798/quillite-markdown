# v3.0.0 detailed changes / 详细更新记录

### 简体中文

- 将“即时渲染／源码”移到编辑标题栏右下方，重新设计为图标与文字结合的等宽双段切换器，增加滑动高亮、左右方向键及减少动画偏好支持，适配明暗主题和窄分栏。

- 最近阅读新增 Ctrl／⌘ 多选与批量清除，支持数量提示、右键操作、Delete 和 Esc；确认后仅移除最近记录及对应置顶，保留文件、收藏与当前未保存文档。写入串行处理，失败项保留选择以便重试。

- 流程图画布新增“输入／输出”平行四边形：支持快捷添加、已有节点切换形状、贴合斜边的连线和 Mermaid 源码往返编辑；图表范例加入输入两个数、计算并输出结果的教学流程。

- 源码模式和图片“查看源码”默认将较长的 Base64 图片编码显示为格式／大小短标签；图片属性仍可编辑，复制、保存及撤回重做保留原始数据，支持明暗主题与双语。

- 修复独立 HTML 图片后紧接的正文无法转换标题：格式命令按需补齐空行，保留图片尺寸、对齐及内容，一次撤回可恢复原文。

- 文字样式图标统一为 16px，与相邻按钮水平对齐；正文／标题菜单独立加宽并居中显示，支持键盘选择、Esc 和点击外部关闭。

- 修复省略行尾竖线的表格在清空末列时丢列、退回源码：删除时按需保留末列边界，空单元格光标不再带入结构空格，避免后续中文组合输入被提前打断；删除与边界修复可一并撤回。

- 修复表格末尾插入图片导致表格退回源码：表格外插图自动补齐分隔空行，保留列宽、内容及单元格内插图，图片与分隔符可一起撤回。

- 工具栏“正文”入口改为醒目的文字样式图标并移到 AI 后方；保留正文／六级标题菜单、双语提示、键盘操作与窄窗口溢出菜单。

- 修复部分可见代码块输入时的页面跳动：未变化的脚注保留区块高度缓存，普通输入不再触发原生／外层滚动，中文组合输入的原生滚动在绘制前受限处理。覆盖长短代码、引用、列表、折叠区、脚注与缩进代码；保留滚轮、主动导航、源码模式及共享撤回／重做。

- 修复多代码块长文档中，底层视图重排短暂移除正在编辑的区块，导致连续输入／中文组合输入失焦并写到开围栏前的问题。保留活动区块连续挂载，正常删除仍生效；补充四区块真实点击、双击／三击、组合输入及精确撤回／重做回归。

- 修复代码块正文光标被外层区块边缘选区通知覆盖的路径，防止后续输入落到隐藏围栏前并破坏后续排版；区块及源码按钮点击不再提前抢焦点。保留显式源码编辑、拖选、中文组合输入与共享撤回。

- 修复鼠标点击长区块“查看源码”时被旧光标拉动页面的问题：切换以区块屏幕位置为锚点，键盘操作和后续输入仍正常定位；新输入、滚动或换文档取消旧的位置补偿，不改变正文和撤回历史。

- 区块源码的“返回渲染”移到源码区块右上方悬停显示，取消占高度的顶部提示栏，避免切换时挤动编辑区域；支持长区块、嵌套区块、键盘焦点和触屏，保留底色、光标及撤回历史。

- 修正上一轮日志修复的两项回归：DOM 结束边界失效时不再读入区块外内容，改为拒绝该变更并恢复已记录文档显示，保留撤回历史；链接地址与标题先单次解码实体再安全转义，修复查询参数和引号重复转义，继续过滤危险协议。

- 区块“查看源码”保留连续底色与圆角边界，包含空行、当前光标行和嵌套区块；适配明暗主题，不改写源码或增加撤回步骤。

- 根据线上错误日志补强：超长正文的 Setext 标题检测改用逐行扫描，避免整段回溯表达式；编辑器读取变动 DOM 时兼容已移除的结束节点；文档／更新／关于等外链统一校验并捕获打开失败，链接地址与标题安全转义。原文、撤回和文件安全限制不变。

- 修复即时编辑与预览的引用／列表差异：按实际嵌套层级绘制引用竖线与列表缩进，区分子列表圆点，统一普通文字样式并补齐子列表结束间距；引用空行和标题后列表空行使用可测量行高。保留源码模式高亮、显式粗斜体／链接／颜色、任务操作和撤回，不改写文档。

- 优化大文档阅读：先显示完整正文，再按视口分帧高亮代码，屏幕外代码／固定列宽表格延后布局；新增最多 4 项／16 MiB 的内存解析缓存，正文、语言或主题变化不复用旧结果。搜索、跳转、打印和导出恢复所需布局，切换文档或进入编辑取消旧任务；超长代码保留完整可复制纯文本。

- 修复即时编辑与分栏预览排版不一致：统一正文、六级标题的字号／字重／行高及二级标题分隔线，补齐连续标题间距。文档开头闭合的 YAML 元数据两侧均按原文显示，不误解析为标题、列表、公式、图片或目录；保留源文档和行号定位。

- 优化文档切换：阅读时不再重复渲染隐藏的编辑预览，取消旧预览图表任务并释放实例；行号映射仅在编辑预览中启用。目录宽度与当前章节更新合并到帧调度，减少同步布局；保留脚注引用、目录跳转、编辑定位及跨文档撤回隔离。

- 修复预览行号映射与自定义链接渲染器上下文不一致导致的 Markdown 渲染失败；普通链接、自动链接和引用链接支持首次及连续打开，异常时恢复解析器状态。切换文档渲染失败时更新文件标识并清除旧正文和目录，避免内容错配。
- PDF 原生引擎全部超时或失败后支持系统打印回退，保留失败诊断；文件占用、权限错误不触发回退，过期文档会话的失败不会打印新文档。

- 修复空白处点击斜体等格式后直接连续输入只保留最后一个字的问题：替换占位文字后立即收起选区并把光标放到新文字末尾，后续输入正常追加；保留跨区块保护、格式标记、撤回和输入法组合事件原有处理。

- 修复注释紧贴标题时整行被误当作 HTML 预览、无法稳定定位删除的问题；顶层正文／标题中空光标插入注释改为当前区块之前的独立注释，保留选中文字及代码／表格内部的原有包裹行为。旧的注释／标题粘连提供“分离注释，恢复标题”，保留注释且可单步撤回；混合或未闭合注释保留可编辑源码，即时模式删除混合注释边界时成对解除标记，避免后文被吞入注释。

- 修复通知遮挡查找／替换输入框和按钮的问题；根据底部编辑面板实测位置避让，窗口调整及查找开关后同步更新，通知隐藏后释放位置监听，不修改正文或撤回历史。
