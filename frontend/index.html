为了尽量保持 Markdown 预览中的表格、代码块和图片样式，轻阅将打开系统打印窗口。请按下面步骤保存为 PDF。

3
选择位置并保存

第 1 步

安装并启动 PicGo

PicGo 是免费的图片上传工具。安装后打开，并让它保持在后台运行。

第 2 步

配置图床并开启 Server

  1. 在 PicGo 中登录 PicGo Cloud，或配置你自己的图床。
  2. 打开“PicGo 设置 → PicGo-Server”，确认服务已开启，端口为 36677。
  3. 保持 PicGo 在后台运行，然后让轻阅自动检测。
✓
第 3 步

PicGo 已连接

保存后，粘贴、拖拽和选择的图片将自动上传；失败时仍会安全使用本地 assets。

高级设置
